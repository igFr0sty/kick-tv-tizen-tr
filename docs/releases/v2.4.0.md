## Türkçe

Kick TV TR, [corekill/kick-tv-tizen](https://github.com/corekill/kick-tv-tizen) projesinin topluluk çatallamasıdır ve resmi değildir.

- Canlı kanalları izleyici sayısına göre gösteren Takip Edilenler ekranı eklendi.
- İsteğe bağlı Kick hesabı eşitlemesi eklendi. Riskleri README'de anlatılıyor.
- Türkçe arayüz ve Türkçe yayın filtresi eklendi.
- Açılışta ilk canlı kanal seçili gelir.
- Orijinal yazarın sunucusunu kullanan hesap girişi, sayaç ve tanılama kaldırıldı.
- Ayrı uygulama kimliği kullanılır, orijinalin yanına kurulabilir.

## English

Kick TV TR is an unofficial community fork of [corekill/kick-tv-tizen](https://github.com/corekill/kick-tv-tizen).

- Added a Following screen that shows live channels sorted by viewer count.
- Added optional Kick account sync. The README explains the risks.
- Added a Turkish interface and a Turkish browse filter.
- The first live channel is selected on launch.
- Removed sign-in, the usage counter and diagnostics, which use the original author's server.
- Uses a separate app ID, so it can be installed next to the original.
